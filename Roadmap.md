# 🚀 AWS Learning Roadmap

A structured path to learn AWS step by step, with checkmarks to track progress.

---

## 1. Foundations (Start Here)
- [X] Understand **Cloud Basics**: IaaS, PaaS, SaaS, regions, availability zones, VPC
- [X] **Compute** → EC2 basics (instances, AMIs, EBS, snapshots)
- [ ] **Storage** → S3 (buckets, lifecycle, Glacier)
- [X] **Networking** → VPC, subnets, Internet Gateway, NAT Gateway, Route Tables, Security Groups
- [X] **IAM** (Identity & Access Management): users, groups, roles, policies

---

## 2. Web Hosting & High Availability
- [X] Elastic Load Balancer (ALB, NLB basics)
- [ ] Auto Scaling Groups (ASG)
- [ ] Elastic IP vs Public IP
- [ ] Route 53 (DNS, domains, health checks)
- [ ] CloudFront (CDN for caching & speed)

---

## 3. Databases & Data Services
- [ ] RDS (MySQL/Postgres, Multi-AZ, Read Replicas, backups)
- [ ] DynamoDB (NoSQL basics)
- [ ] ElastiCache (Redis/Memcached for caching)
- [ ] Amazon Athena & QuickSight (serverless queries + visualization)
      
---

## 4. Serverless & Application Development
- [ ] Lambda (serverless functions)
- [ ] API Gateway (expose APIs)
- [ ] SQS & SNS (messaging, notifications)
- [ ] Step Functions (workflow orchestration)

---

## 5. DevOps & Infrastructure as Code
- [ ] CloudFormation (infrastructure templates)
- [X] Terraform (IaC multi-cloud)
- [ ] CI/CD with CodePipeline, CodeBuild, CodeDeploy
- [ ] Monitoring:
  - [ ] CloudWatch (logs, metrics, alarms)
  - [ ] X-Ray (app tracing)

---

## 6. Security & Best Practices
- [ ] KMS (Key Management Service – encryption)
- [ ] Secrets Manager / Parameter Store
- [ ] AWS WAF & Shield (web app protection)
- [ ] GuardDuty, Inspector (threat detection)


---

## 7. Advanced Topics
- [ ] Containers:
  - [ ] ECS
  - [ ] Fargate
  - [ ] EKS (Kubernetes on AWS)
- [ ] Big Data:
  - [ ] EMR
  - [ ] Redshift
  - [ ] Kinesis
- [ ] Machine Learning:
  - [ ] SageMaker basics
- [ ] Migration strategies (on-prem → AWS)

---

## 8. Certifications Path
- [ ] **AWS Certified Cloud Practitioner (CCP)**
- [ ] **AWS Certified Solutions Architect – Associate (SAA-C03)**
- [ ] Choose specialization:
  - [ ] SysOps Administrator – Associate
  - [ ] Developer Associate
  - [ ] DevOps Engineer – Professional

---

✅ By completing this roadmap, you’ll move from **beginner → intermediate → professional AWS engineer**.
